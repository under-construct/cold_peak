# Вершина — Android-версия

Игра лежит в `app/src/main/assets/index.html` и запускается во весь экран в портретной ориентации.
Сохранения работают так же, как в браузере. Кнопка «Назад» = Esc (закрыть окно).

## Вариант 1 — без установки чего-либо (GitHub Actions)
1. Создайте новый репозиторий на github.com и загрузите в него содержимое этой папки
   (кнопка «Add file → Upload files», перетащите всё, включая папку `.github`).
2. Откройте вкладку **Actions** — сборка «Собрать APK» запустится сама (~5 минут).
3. Откройте завершённый запуск → внизу раздел **Artifacts** → скачайте `Vershina-apk`.
   Внутри архива — `app-release.apk`.
4. Перекиньте APK на телефон и установите (разрешите «установку из неизвестных источников»).

## Вариант 2 — Android Studio
1. File → Open → выберите эту папку, дождитесь синхронизации Gradle.
2. Build → Build App Bundle(s) / APK(s) → Build APK(s).
3. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Обновить игру
Замените `app/src/main/assets/index.html` новой версией и пересоберите
(в варианте 1 — просто загрузите новый файл в репозиторий, APK соберётся заново).

APK подписан отладочным ключом — подходит для установки на свои устройства.
Для публикации в Google Play нужен собственный ключ подписи.
